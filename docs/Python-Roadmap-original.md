# 🗺️ Python Roadmap: від нуля до перших грошей за 9 місяців

> Створено: 21.09.2026
> Темп: 1,5–2 години щодня. Ключ — регулярність, а не марафони.
> ⚡ Ваш темп: ПРИСКОРЕНИЙ (3 тижні програми за 2 дні!). Тижні нижче — орієнтир, а не дедлайн: ідете своїм темпом, уроки видаються по готовності.

## 📊 Загальна картина

```
Місяці 1–2   → База Python (пишете РУКАМИ, без ШІ)
Місяці 3–4   → Інструменти + перші проєкти на GitHub
Місяці 5–6   → Спеціалізація під гроші (боти/парсинг/AI)
Місяці 7–9   → Портфоліо + перші замовлення на фрілансі
```

## 📆 МІСЯЦЬ 1 — База, частина 1

### Тиждень 1: Старт і змінні
- [x] Встановити Python (python.org → Downloads → галочка "Add Python to PATH")
- [x] Встановити VS Code (або PyCharm Community — безкоштовний)
- [x] `print()`, змінні, типи даних (`int`, `str`, `float`, `bool`)
- [x] `input()`, умови `if / elif / else`
- [x] 🎯 МІНІ-ПРОЄКТ: калькулятор у консолі

### Тиждень 2: Цикли і списки
- [x] Цикли `for`, `while`
- [ ] Рядки: зрізи, методи (`upper`, `split`, `replace`...)
- [ ] Списки: `append`, перебір, `len`
- [x] 🎯 МІНІ-ПРОЄКТ: гра «Вгадай число» (ex3.py ✅)

### Тиждень 3: Функції і словники
- [ ] Словники (`dict`), кортежі (`tuple`), множини (`set`)
- [ ] Функції: аргументи, `return`
- [ ] 🎯 МІНІ-ПРОЄКТ: консольний менеджер витрат

### Тиждень 4: Файли і помилки
- [ ] Читання/запис файлів (`open`, `with`)
- [ ] Обробка помилок: `try / except`
- [ ] Модулі: `import`, `random`, `datetime`
- [ ] 🎯 ФІНАЛЬНИЙ ПРОЄКТ МІСЯЦЯ: трекер витрат зі збереженням у файл (БЕЗ ШІ!)
