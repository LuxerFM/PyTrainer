# 🐍 PyTrainer — тренажер Python

Десктопний тренажер, у якому ти **пишеш код руками**, а програма його реально
запускає й перевіряє прихованими тестами. Не «курс із відповідями», а щоденний
інструмент: задача → спроба → вердикт → повторення через 1/3/7/30 днів.

Інтерфейс на PySide6 (Qt 6), логіка — на чистому Python зі стандартної бібліотеки.

## Швидкий старт

Windows — просто подвійний клік на **`start.bat`** (першого разу він сам створить
оточення й встановить PySide6).

Вручну, з терміналу:

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt   # Windows
.venv/bin/python -m pip install -r requirements.txt            # Linux/macOS
.venv\Scripts\python.exe main.py
```

## Що вміє

**Три панелі, як у справжній IDE.** Зліва — шлях навчання на 9 місяців, по центру —
редактор коду з номерами рядків і підсвіткою синтаксису, справа — умова задачі,
перевірки, підказки та історія спроб.

**Чесна перевірка.** Твій код виконується в окремому процесі Python із таймаутом
5 секунд, тому навіть `while True` не зашкодить програмі. Перевірки бувають двох
видів: `assert`-и по функціях і перевірки того, що програма надрукувала —
з підстановкою вводу замість клавіатури (задачі з `input()` теж перевіряються).

**Підказки без спойлерів.** Три рівні: «де шукати» → «яка конструкція» → повний
розв'язок. Розв'язок заблоковано, поки не набіжить 10 хвилин активної роботи над
задачею. Кожна підказка зменшує XP за задачу — думати самому вигідно.

**Черга повторень.** Задачу, здану не з першого разу, завалену або ту, де ти
підглянув розв'язок, тренажер поверне через 1 день, потім 3, 7 і 30. Після п'ятого
успішного повторення задача вважається засвоєною.

**Прогрес, XP і слабкі місця.** Стрік днів, XP (з урахуванням підказок),
відсоток успішних спроб, топ тем, у яких провалюєшся, і календар активності на 8 тижнів.

**Роадмап оновлюється сам.** Файл `Python-Roadmap.md` генерується із навчального
плану: коли здаєш задачу, галочка ставиться автоматично.

## Структура проєкту

```
main.py                  точка входу
curriculum/              навчальний план: місяці, теми, задачі з тестами й підказками
  schema.py              структура даних + конструктори task(), code(), stdout(), hint()
  month1.py              18 готових задач (усі з розв'язками, які перевіряються тестами)
  month2.py …            інші місяці: план уже є, задачі додамо далі
  roadmap_md.py          генератор Python-Roadmap.md
trainer/core/            логіка без інтерфейсу
  runner.py              запуск коду в окремому процесі + приховані перевірки
  scoring.py             правила XP, інтервалів і серії днів
  db.py                  SQLite: прогрес, спроби, підказки, час, повторення
  stats.py               статистика по темах і пошук слабких місць
trainer/ui/              інтерфейс
  theme.py               темна тема (палітра + QSS)
  editor.py              редактор: номери рядків, підсвітка, автовідступ
  sidebar.py             ліва колонка: шлях / повторення / прогрес
  task_panel.py          права колонка: умова, тести, підказки, історія
  main_window.py         зшиває все разом
tests/                   73 тести (ядро, база, правила, план, інтерфейс)
tools/                   службові скрипти
```

## Гарячі клавіші

| Клавіші | Дія |
|---|---|
| `Ctrl+Enter` | запустити код |
| `F5` | перевірити прихованими тестами |
| `Ctrl+N` | наступна незавершена задача |
| `Ctrl+R` | черга повторень |
| `Ctrl+P` | прогрес і слабкі місця |
| `Tab` / `Shift+Tab` | відступ / зменшити відступ |
| `Ctrl+S` | зберегти код у файл |

## Додати свою задачу

Задачі — це дані, а не код інтерфейсу. Відкрий відповідний файл у `curriculum/`
і додай у тему:

```python
task(
    id="w2-my-task",
    title="Порахуй середнє",
    level="Середньо",
    statement="<p>Напиши <code>average(numbers)</code>…</p>",
    starter="def average(numbers):\n    return 0\n",
    checks=[
        code("рахує середнє", "assert average([2, 4]) == 3"),
        code("порожній список", "assert average([]) is None"),
    ],
    hints=[
        hint("де шукати", "sum() і len() — твої друзі."),
        solution("def average(numbers):\n    return sum(numbers) / len(numbers) if numbers else None"),
    ],
)
```

Далі `python -m unittest discover -s tests` — і тести самі перевірять, що твій
розв'язок проходить власні перевірки, а заготовка коду — ні.

## Тести

```bash
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Найцінніший тест — `test_curriculum.py`: він запускає **кожен розв'язок** проти
перевірок його ж задачі. Якщо задача зламана, це видно одразу.

## Дані

- `pytrainer.db` — прогрес (SQLite, створюється сам).
- `Python-Roadmap.md` — генерований роадмап. Ручні правки в ньому перезапишуться:
  власні нотатки веди тут, у README.
- Код, який ти не довів до кінця, зберігається в базі — перемикання між задачами
  його не втрачає.

## Правила навчання (з роадмапу)

1. **Місяці 1–2 — ШІ тільки як учитель.** Питай «поясни, чому не працює», а не
   «напиши за мене». Код — руками.
2. **Місяць 3+ — правило 20–30 хвилин.** Спершу сам, потім ШІ.
3. **Розв'язок у тренажері відкривається після 10 хвилин роботи.** Це не покарання,
   а захист від «подивлюсь і зрозумію».
